# Zeal 2 Up — Full-Stack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build "Zeal 2 Up" — an AI-powered student counselling, psychological assessment, and behavioural evaluation platform for colleges and universities.

**Architecture:** Next.js 15 App Router + Supabase (Auth/DB/Realtime/Storage) + OpenAI streaming chat. Role-based routing via middleware with three actor types: student, expert, admin. Assessment results drive PDF reports and dashboard analytics.

**Tech Stack:** Next.js 15, TypeScript strict, Tailwind v4, shadcn/ui New York, Supabase, OpenAI SDK, jsPDF, Recharts, Framer Motion, TanStack Query, React Hook Form + Zod, WebRTC

---
